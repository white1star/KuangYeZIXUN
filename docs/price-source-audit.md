## 0. 一句话结论

**够用，而且不是"一个源"——长江有色报价接口本身就是一套"按市场分列"的现货报价体系**：
14 个金属品类、每品类 21 条市场报价、自带报价市场/产地/牌号/规格/最高最低均价/振幅/单位/报价日。
所谓"每个地区价格不一样"的数据，源站本来就给全了，是**当前解析器只取 (品名, 价格) 两个字段就丢掉了**。

不需要引入新数据源，需要做的是：把已有字段结构化入库 + 修掉错误匹配。

### 1.5 ⚠️ 口径风险（必须处理）

1. **加工材混入**：佛山现货的 `1#电解铜板` 95,400 是电解铜+加工费，与 `1#电解铜` 110,730 **不是同一商品**。
   → 品种必须按 `productSortName` + `trademark` 精确锁定，不能按"含铜字"匹配。
   （线上现在显示的"铜 现货 59,100 = 破碎黄铜"就是同一个根因）
2. **市场名 ≠ 到厂价**：marketName 是报价市场（长江现货/无锡现货/佛山现货/上海地区），
   不含运费、到厂价、税费口径；长江有色系报价通常含税（列表页表格另有"含税/不含税"列明确标注）。
3. 小金属区域价差很小（几十元），**价差信息只在"日级别"才有意义**（看区域普涨/分化，不看绝对值差）。

## 2. 其余源：可得维度与当前落差

### 2.1 生意社 100ppi（`pp100`，table 解析）—— 煤炭/非金属矿的地区与规格最全

- 8 个品类页，抓到 **212 行报价、12 个地区**：上海、安徽池州、山东、山西、广西、江苏常州、江西、河北、河南、河南郑州、湖北武汉、湖南
- 表格列（**当前只取第 0、3 列**）：

  | 列 | 含义 | 当前 |
  |---|---|---|
  | 0 | 品名 | ✅ 取 |
  | 1 | **规格**（萤石含纯度与含水率、焦煤含粘结指数/挥发分/胶质层/奥亚膨胀） | ❌ 丢 |
  | 2 | 产地属性（国产） | ❌ 丢 |
  | 3 | 价格（字符串内嵌单位，如 `1700元/吨`） | ✅ 取（剥数字） |
  | 4 | **价格类型**（市场价 / 出厂价） | ❌ 丢 |
  | 5 | **地区** | ❌ 丢 |
  | 6 | 报价企业 | ❌ 丢 |
  | 7 | 报价日期 | ❌ 丢 |

- 分页：`plist-1-{cat}-{pageNo}.html` 有效 —— 焦煤 30+24 行（第 3 页空），钼酸铵 30+30+21 行；其余品类单页即全量

## 4. 结论与落地清单

### 4.1 够用的部分（不需要新源）

- **有色/小金属/铁合金的区域价**：长江有色接口 14 品类已覆盖，自带市场+产地+牌号+规格+振幅
- **矿石（红土镍矿，带品位）**：长江 `jskc` 已有
- **铁精矿（带品位、带地区）**：长江列表页第 5 表已有
- **煤炭的港口/长协/热值口径**：cctd 已有
- **非金属矿的地区+规格**：生意社已有（萤石/石英砂/钼酸铵/焦煤）
- **煤焦的产地指数**：sxcoal 已有（地区限定词在指数名里）

### 4.2 建议改造（P0 修错 → P1 加维度 → P2 展示）

**P0 止血**
1. ccmn 列表页：按 `productSortName` 精确匹配品种（1#电解铜 / A00铝），废料表单独过滤；或整体改走 `mall` 接口（口径干净、有市场维度）
2. "全部类型"改为多系列图或下掉
3. 期货涨跌按昨结算计算；现货/指数涨跌用库内前值补算

**P1 加维度**（prices 表）
```
market   TEXT   报价市场/交割地   长江现货/无锡现货/佛山现货/上海地区/秦皇岛/山西…
origin   TEXT   产地/牌号        国产/云锡/大冶/赤峰/吕梁…
spec     TEXT   规格/品位        1# / Φ8 / 65-67品位 / 红土镍矿1.5% / Q5500
basis    TEXT   税与交割口径      含税/不含税/含税承兑/到厂/CFR/FOB/昨结算
contract TEXT   期货合约          CU2611 / JM2611
```
唯一键改为 `UNIQUE(commodity, market, price_type, spec, price_date, source_key)`

**P2 展示**
- 类型筛选拆成 市场 / 口径 / 规格
- 表格加"市场"列，同品种多市场并列，末尾给"最高/最低/价差"
- 期货标合约月；单位在品种处标注一次
- 可选：区域价差图（各市场价格走势叠加）与基差视图

## 实施记录（P0 + P1，2026-10-21）

### A. 数据模型：prices 表加口径维度

```sql
market   TEXT  -- 报价市场/交割地：长江现货 / 无锡现货 / 佛山现货 / 秦皇岛 / 吕梁 …
origin   TEXT  -- 产地/牌号：国产 / 云锡 / 大冶 / 青岛 / 凉山 …
spec     TEXT  -- 规格品位：1# / 20% / Q5500 / FeNi4-8 / 含镍3.8-4.0%
basis    TEXT  -- 税与交割口径：含税 / 不含税 / 不含税·昨结算 / 市场价 / 出厂价
contract TEXT  -- 期货合约：连续 / CU2611

UNIQUE(commodity, price_type, market, spec, price_date, source_key)
```

迁移在 `crawler/store.py::_migrate_prices`（重建表换唯一约束）+ `_prune_legacy_prices`
（清掉换口径源的空口径历史行）+ `_backfill_legacy_market`（给指数旧行按 raw_label 回填市场）。

### B. 解析器：把源站已有字段取出来

| 改动 | 位置 | 效果 |
|---|---|---|
| 精确匹配模式 `exact_match` | `price_sources._match_commodity` | 列表页不再命中"破碎黄铜/马达铜/破碎熟铝" |
| 表格源角色化列 | `price_sources.parse_table` | 支持 spec/market/origin/basis/unit/date 列 |
| 正则源多捕获组 | `price_sources.parse_regex` | 支持 market/spec/change/change_pct/date + market_map/spec_map/price_type_map |
| 长江报价接口逐市场出价 | `price_sources.parse_ccmn_quota` | 21 条市场报价逐条入库，不再跨市场平均 |
| 期货合约与税口径 | `parse_futures_sina` / `parse_futures_eastmoney` | basis="不含税·昨结算"、contract=连续/合约月 |

### C. 源配置
