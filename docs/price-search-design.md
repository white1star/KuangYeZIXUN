# 矿价搜索设计（待确认）

目标：销售在矿价页**一步找到"某矿种在某地多少钱"**，并能把报价直接发给客户。

## 1. 场景与入口

| 场景 | 销售输入 | 期望结果 |
|---|---|---|
| 知道矿种 | `萤石` / `ys` / `97粉` | 萤石各地报价 + 走势 |
| 知道客户所在地 | `广西` / `唐山` | 该地区全部品种报价 |
| 知道用途/规格 | `PB粉` / `65品位` / `湿吨` | 对应规格的报价 |
| 记不清名字 | `铜`（想找铜精矿） | 建议列表：铜 / 铜精矿 / 废铜，可点选 |

入口：矿价页顶部**一个搜索框**，取代现在的"品种"下拉（69 个品种的下拉已经不好用）。

## 2. 交互

```
[🔍 搜矿种 / 地区 / 规格，如：萤石、广西、PB粉     ]  ← 输入即过滤
   ┌──────────────────────────────┐
   │ 品种  萤石        （5 个市场） │  ← 建议分「品种」「地区」两组
   │ 品种  萤石粉                  │
   │ 地区  广西                   │
   └──────────────────────────────┘
```

- **输入即出建议**（前端过滤，无请求）
- 选中品种 → 图表切到该品种 + 表格只留该品种
- 选中地区 → 表格按该地区过滤（跨品种，看"广西都有什么价"）
- **URL 同步**：`?q=萤石&market=广西` → 可收藏、可发同事
- **一键复制**：`萤石 97%湿粉 广西 1700元/吨 2026-10-23 来源：生意社`（粘贴给客户）
- **最近查看**（localStorage，最多 8 条）置顶
- 无结果时给"最接近的品种"，不留白页

## 3. 匹配规则

| 匹配对象 | 例子 | 说明 |
|---|---|---|
| 品种名 | 萤石 → 萤石 | 精确/前缀优先 |
| 别名 | 电解铜/1#铜 → 铜；金子 → 黄金 | 需维护别名表 |
| 拼音首字母 | ys → 萤石；fst → 废不锈钢 | 构建时生成，不引前端库 |
| 规格 | 97、PB粉、65品位、湿吨 | 匹配 spec 字段 |
| 市场/地区 | 广西、唐山、长江 | 匹配 market（`河北省/唐山市` 可被"唐山"命中） |
| 来源 | 生意社、长江有色 | 可选 |

匹配顺序：品种 > 别名 > 地区 > 规格；同分按"数据条数多"排。

## 4. 数据层（不新增后端）

- 构建时从 `prices.json` 生成一份 `search.json`：`{品种, 别名[], 拼音, 规格[], 市场[], 省份[]}`
- 约 69 品种 × 若干关键词 ≈ 20KB（gzip 后几 KB）
- 全部前端过滤，静态站和动态站都能用
- 别名表放 `config/price_aliases.yaml`，人工维护，随构建打包

```yaml
# config/price_aliases.yaml
铜: [电解铜, 1#铜, 阴极铜, cu]
萤石: [氟石, 萤石粉, caf2]
铜精矿: [铜矿, 铜精粉]
废铜: [废杂铜, 光亮铜]
```

> 注意：**别名不能跨品种**。`铜` 不包含 `铜精矿`（两个不同商品，价格差 3 倍）。

## 5. 移动端（销售在外面用）

- 搜索框固定在页面顶部，滚动时可见
- 搜索结果 **卡片式**（品种 / 市场 / 价格 / 涨跌 / 日期），不是横向溢出的大表格
- 一键复制按钮放大，方便单手点

## 6. 与"到厂价"的衔接（第二期）

销售搜"广西 萤石"时，除了显示广西本地报价，再补一行：
`无广西本地报价时可参考：江西（约 420km）1700 元/吨` —— 为下一步"最近市场 + 运费"估算留出位置。

## 7. 实现拆分

| 步骤 | 内容 | 预估 |
|---|---|---|
| 1 | 搜索框 + 前端索引 + 建议下拉 + 结果联动 + URL 同步 + 一键复制 | 1-2 天 |
| 2 | 别名表 + 拼音首字母 + 规格/地区匹配 | 0.5-1 天 |
| 3 | 移动端卡片布局 + 最近查看 | 0.5-1 天 |
| 4（二期） | 省份聚合 + 最近市场推荐 + 运费估算 | 待定 |

## 8. 需要你确认的点

1. **搜索框是否直接取代"品种"下拉**？（保留下拉也可以，但 69 项下拉很难用）
2. **别名表谁来定**：销售平时怎么叫这些矿？（"氟石""萤石粉""97粉"这类叫法各地不同）
3. **地区粒度**：只到省市（广西、唐山）够不够，还是要到"港口/矿区"（曹妃甸、防城港、大冶）？
4. **移动端优先级**：销售主要在手机上用，还是回办公室用电脑？
5. **一键复制的格式**：销售发给客户的一般是什么格式？（例：`萤石97%湿粉 广西 1700元/吨`）

## 9. v2 实现（参考成熟行情产品后重做）

参考对象与借鉴点：

| 产品 | 借鉴的结构 |
|---|---|
| 东方财富 / 同花顺 行情中心 | **左侧分面树 + 右侧内容**；搜索联想分组；自选置顶；`/` 快捷聚焦 |
| 生意社 报价中心 | 品种分类树 + 每项报价条数；地区/规格作为二级维度 |
| SMM（掌上有色） | 品种 → 地区 → 规格三级下钻；移动端抽屉式筛选 |
| 淘宝 / 1688 搜索 | 空态给「最近搜索 / 热门」；关键词高亮；结果计数 |

具体结构：

- **顶部搜索**：空态显示 最近搜索 / 常用 / 热门品种；输入中给分组联想（矿种 / 地区），
  关键词高亮，底部显示"共 N 个匹配"；支持 上下键 / Enter / Esc、`/` 聚焦
- **左侧分面树**：常用（自选）→ 品种（9 个分类，每项带条数）→ 地区（26 个省，点省下钻到市场）
- **右侧内容**：图表 + 报价表；表格头有"看全部品种"开关；筛选条（chips）可单独清除
- **组合查询**：`广西 萤石` 一次同时筛品种和省份（联想里显示为"矿种 + 地区"）
- **匹配**：多关键词 AND、全拼（`ying shi`）+ 首字母（`ys`）+ 别名、规格（`PB粉`）
- **移动端**：分面树收进抽屉（"筛选"按钮），表格变卡片
- **URL**：`?commodity=萤石&province=广西&ptype=现货&days=30&all=1` 可分享

与 v1 的差异：v1 只有下拉联想，没有分面、没有最近/热门、没有组合查询、拼音只支持首字母。
