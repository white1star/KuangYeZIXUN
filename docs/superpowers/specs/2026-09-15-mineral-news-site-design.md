# 矿业资讯内部站（唐山像素智能）— 设计文档

- 日期：2026-09-15
- 状态：待用户终审
- 项目代号：矿_news（内部资讯站）

---

## 1. 背景与目标

唐山像素智能科技有限公司（XIANGSU）主营 XRT 智能分选机与 AI 色选机，为煤矿及金、铜、铅锌、锰、钨、钼、锑、锡、磷、萤石、石英等矿山客户提供干法智能分选设备与方案；客户覆盖国内 7 省及海外 5 国（蒙古、缅甸、柬埔寨、伊朗、赞比亚），公司约 42 人。

**现状痛点**：矿石新闻、矿种价格、国家政策全靠员工各自人肉浏览，"费时、怕漏、信息不统一、无沉淀"。

**目标**：做一个公司内网网站，每天早/中/晚自动抓取三大板块内容，全员可看、可筛选、可搜索历史。

## 2. 需求确认（访谈结论）

| 维度 | 结论 |
|---|---|
| 使用者 | 全员（约 42 人），无差别开放 |
| 核心功能 | 自动分类 + 标签筛选；自动去重；历史搜索/存档 |
| 明确不做 | 推送（不做企业微信/钉钉/邮件）；AI 摘要/每日综述；账号登录 |
| 部署 | 办公电脑（Windows，常开机），内网访问，无密码 |
| 抓取节奏 | 每天 3 次：07:30 / 12:30 / 18:30（可配置） |
| 信息源 | 免费公开源，由开发方调研确认（见第 7 节） |
| 维护方式 | 主要靠 AI 后续维护 → 配置化、少依赖、中文文档、管理页 |
| 技术路线 | 路线 A：分离式本地应用（抓取器与网站进程隔离） |

## 3. 非目标（v1 不做）

- 不做推送与订阅提醒（二期）
- 不做 AI 摘要、每日综述（二期）
- 不做登录/权限体系（内网无密码）
- 不做公众号抓取（微信生态成本高，行业站转载可覆盖大部分）
- 不做移动 App（响应式网页即可）
- 不做评论、点赞、收藏、导出

## 4. 总体架构

```
办公电脑（Windows）
├─ 抓取器 crawler/         Python 脚本，计划任务 07:30/12:30/18:30 触发
│                          每次全新进程；单源故障隔离
├─ 网站服务 web/           常驻进程，http://<本机IP>:8080（无密码）
│                          看门狗定时健康检查，挂了自动拉起
├─ 配置 config/            sources/*.yaml + tags.yaml（加源/改源/改词典不改代码）
├─ 数据 data/              SQLite 单文件 + 每日自动备份（保留 30 天）
└─ 日志 logs/              按天滚动，中文可读，供 AI 排错
```

**技术选型**

- 语言：Python 3.11+
- 抓取：requests + BeautifulSoup/lxml；编码按源声明处理（含 GBK/GB2312）
- 存储：SQLite（含 FTS5 全文索引；中文用 trigram 分词）
- Web：FastAPI + Jinja2 服务端渲染 + 少量原生 JS；ECharts 本地打包（不依赖外网 CDN）
- 定时：Windows 计划任务直接调用 `python.exe`（绝对路径），运行期不经过 .bat
- 安装：`python 安装.py`（建虚拟环境、装依赖、注册计划任务、配防火墙、关睡眠、打印访问地址）；可选提供一行转发式 `安装.bat`，逻辑为零

## 5. 运行、自愈与运维

- **安装**：前置仅需安装一次 Python（勾选 Add to PATH）；其余一条命令自动完成
- **开机自启**：网站服务注册为"登录时启动"计划任务；三次抓取任务勾选"错过时间后尽快补跑"（电脑关机再开机自动补当天任务）
- **看门狗**：每 5 分钟健康检查一次，服务无响应则自动重启
- **备份**：每日自动备份 SQLite 到 `data/backup/`，保留 30 天
- **电源策略**：安装脚本自动设置"从不睡眠"（仅限本机）
- **管理页**：浏览器内完成"立即抓取一次 / 查看源健康 / 下载日志 / 导出备份"，日常不需要命令行

## 6. 数据模型（概要）

| 表 | 关键字段 |
|---|---|
| articles | id, url, url_hash, title, summary(≤200字), source_key, published_at, fetched_at, board(价格/政策/新闻), minerals[], regions[], cluster_id, is_primary |
| article_clusters | id, primary_article_id, member_count（用于"另有 N 家转载"） |
| prices | id, commodity, price_type(期货/现货/指数), value, unit, change, change_pct, price_date, source_key, raw_label |
| sources | key, name, board, url, enabled, config_json, 最近运行状态 |
| crawl_runs | id, source_key, started_at, finished_at, status, items_found, items_new, error |

**存储红线**：只存标题 + ≤200 字摘要 + 原文链接 + 元数据，不存正文全文。

### 7.4 抓取合规红线

- 只存标题 + ≤200 字摘要 + 原文链接，不存全文
- 单源请求间隔 1–2 秒，礼貌访问；不绕过登录墙/验证码
- 遵守各站 robots 中明确的拒绝条款；被明确封禁的源直接下线并告警

## 8. 分类与去重规则

**分类**：来源定板块（政策站→政策，行情→价格，其余→新闻）；YAML 词典定矿种/类型/地区标签，一篇文章可多标签。示例：《河北开展磷矿安全生产整治》→ `磷矿` + `政策` + `河北`。

**去重（三层）**

1. 完全重复：URL 归一化（去跟踪参数）+ 标题去噪哈希 → 丢弃
2. 转载/近似：标题 3-gram Jaccard 相似度 ≥ 0.85 → 归入同一 cluster，保留最早一条为正文，页面显示"另有 N 家转载"
3. 同源更新：同一 URL 内容变化 → 原地更新，不新增

阈值、词典全部放配置文件。

## 9. 功能与页面

| 页面 | 内容 |
|---|---|
| 首页·今日速览 | 顶部状态条：`今日新增 N 条 · 上次抓取 12:30 成功 · [3 次抓取状态灯]`；中部新闻流（时间倒序）；右栏矿价速览卡（常用品种涨跌红绿）+ 最新政策 |
| 行情页 | 按矿种分组报价表（品种/最新价/涨跌/涨跌幅/数据日期/来源）+ 近 7/30/90 天走势图；期货与现货分区标注 |
| 政策页 | 按发布机关/地区筛选，时间倒序 |
| 搜索页 | 关键词 + 矿种/类型/来源/时间范围组合筛选（FTS5，万级数据 <1 秒） |
| 源健康（管理） | 各源最近抓取成功/失败/条数、日志下载、`立即抓取一次`（防连点）、导出备份 |

**体验要求**：响应式（手机可用）；打开首页 3 秒内能判断"今天有没有大事"。

## 10. 错误处理

- 每个源独立 try/catch + 超时（15 秒/请求）；单源失败只记日志，不中断整轮抓取
- 每轮抓取生成 crawl_runs 记录，源健康页可视化
- 解析失败自动保留原始 HTML 快照（最近 3 次）供 AI 修解析用
- 网站服务崩溃由看门狗拉起；计划任务"错过补跑"

## 11. 验收标准与测试

| 项 | 标准 |
|---|---|
| 部署 | 从零到跑通 ≤ 30 分钟；电脑重启后无需人工干预 |
| 覆盖 | 源清单 ≥90% 正常出数；单源故障不影响全局；价格品种 ≥12 个持续更新 |
| 数据质量 | 抽检 20 条：标题/链接/时间/标签正确率 ≥95%；页面可见重复 <2% |
| 功能 | 搜索万级数据 <1 秒；走势图正确；转载合并正常 |
| 体验 | 手机打开首页 ≤2 秒；3 秒判断"今天有没有大事" |
| 稳定 | 连续 7 天无人值守不崩（崩了自动恢复） |

**测试方式**：每个源配离线 HTML 样本 + 解析断言（源改版时测试先红）；上线前连续试运行 3 天，以"源健康"页为准。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 源站改版（必然发生） | 配置化解析 + 离线样本测试 + 原始快照，AI 修复成本低 |
| 反爬升级 | 降频、换等价源、二期浏览器方案 |

| 单点（一台电脑） | 每日备份；二期可整体迁移云服务器 |

## 附：本设计的关键决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 技术路线 | A：分离式本地应用 | 故障隔离、AI 可维护、零成本 |
| 推送 | 不做 | 用户明确不要；以首页"今日速览"兜底"怕漏" |
| AI 摘要 | 不做 | 用户未选；分类去重走规则+相似度，零 API 成本 |
| 登录 | 不做 | 内网物理隔离 |
| 公众号 | 不抓 | 成本/合规；行业站转载覆盖 |
| 期货源 | 新浪/东财替代交易所官网 | 交易所硬 WAF；行情数据同源等效 |
| 存储 | 只存标题+摘要+链接 | 版权友好、库小 |
